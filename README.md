🎯 Sobre o Projeto
Este projeto é uma recriação da interface da HBO Max, desenvolvido como parte de um desafio da Digital Innovation One (DIO). O objetivo é praticar e demonstrar habilidades em desenvolvimento web front-end, incluindo design responsivo, animações CSS e interatividade com JavaScript.

✨ Características Principais:
🎨 Design Moderno: Interface fiel ao estilo HBO Max
📱 Totalmente Responsivo: Adaptável a dispositivos móveis, tablets e desktops
🎭 Efeitos Interativos: Hover effects e micro-interações
🌈 Gradientes Personalizados: Esquema de cores roxo/magenta característico da HBO
